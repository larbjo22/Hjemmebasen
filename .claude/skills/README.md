# Skills

Claude Code-skills for design- og animasjonsarbeid i Hjemmebasen.

## Kilde

Skill-ene her er hentet fra **[emilkowalski/skills](https://github.com/emilkowalski/skills)**
(Emil Kowalski), lisensiert under MIT – se `LICENSE-emil-skills`.

| Skill | Kort |
|---|---|
| `emil-design-eng` | Emils filosofi om UI-polish, komponentdesign og animasjon |
| `review-animations` | Streng gjennomgang av animasjonene dine mot faste regler |
| `improve-animations` | Auditerer animasjonene i kodebasen og gir prioriterte planer |
| `find-animation-opportunities` | Finner steder i UI-et som ville tjent på bevegelse |
| `animation-vocabulary` | Presist vokabular for å beskrive animasjoner |
| `apple-design` | Apples prinsipper for grensesnitt og flytende bevegelse |
| `pick-ui-library` | Velger etablerte, vedlikeholdte UI-biblioteker |

## Bruk

I en Claude Code-økt: skriv `/<skill-navn>` (f.eks. `/emil-design-eng`),
eller be Claude bruke skillen. Nye skills plukkes opp ved oppstart av en økt.
